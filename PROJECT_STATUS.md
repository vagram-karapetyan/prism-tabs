> **Дата обновления:** 3 ноября 2026 г.

## 🚀 Что уже сделано (Implemented)

### 1. Архитектура двух движков (Dual-Engine)
- [x] **⚡ Logic Mode (Детерминированный офлайн-движок `<1ms`)**:
  - 60+ преднастроенных профилей сервисов (Google Suite, GitHub, Jira, Figma, соцсети, медиа и др.).
  - Распознавание деревьев вкладок по `openerTabId` (родитель-потомок).
  - Сходство заголовков по алгоритму Jaccard NLP.
  - Кастомные правила пользователя (hostname, URL, путь, регулярные выражения Regex).
  - Эвристика объединения поддоменов и разбиения по сегментам пути URL.
  - Умное разделение поисковиков (Yandex Search) и медиа-сервисов (Yandex Music → Media & Audio).
- [x] **✨ Meaning Mode (Семантический AI через BYOK)**:
  - Мульти-провайдерная интеграция: **Groq LPU** (с авторотацией моделей при исчерпании TPM), **Google Gemini 2.5 Flash**, **OpenAI-совместимый Custom API**.
  - Автоматический Sanitizer: очистка приватных URL, токенов, chrome:// протоколов перед отправкой в LLM.
  - Поддержка кастомных директив и готовых пресетов сортировки (Work/Personal, Urgent triage и др.).
  - Грациозный fallback на Logic Mode при обрыве сети или превышении лимитов.

### 2. Умное управление вкладками (Tab Management)
- [x] **Smart Merge**: сохранение существующих групп и неразрушающее добавление новых вкладок без дублирования.
- [x] **Автоматическая очистка пустых вкладок**: закрытие пустых `New Tab` / `about:blank`.
- [x] **Автозакрытие главной страницы YouTube**: опция закрытия стартовой `youtube.com/` при группировке видео.
- [x] **Auto-collapse inactive groups**: автоматическое сворачивание неактивных групп на панели вкладок.
- [x] **Active Window Isolation**: изолированная работа строго в активном окне Chrome без влияния на другие окна.
- [x] **Полный Undo (`Ctrl+Z`) и Ungroup All (`Alt+U`)**: моментальный откат состояния структуры вкладок в 1 клик.
- [x] **Живое редактирование групп**: смена названия, цвета метки Chrome и роспуск прямо из попапа.

### 3. Современный UI и система тем
- [x] **6 дизайнерских цветовых тем оформления**:
  1. `🌈 Prism Deep` (тёмный космический нуар, дефолтная тема)
  2. `🌌 Midnight Nebula` (киберпанк-неон)
  3. `🌲 Emerald Forest` (северная хвоя и изумруд)
  4. `☕ Sunset Amber` (теплый эспрессо и бронза)
  5. `❄️ Arctic Frost` (полярный лед и титан)
  6. `☀️ Pure Light` (чистая светлая тема с высоким контрастом)
- [x] **Визуальный селектор тем** с предпросмотром палитры.
- [x] **Полная адаптация светлого режима**: устранены проблемы контраста («белый текст на белом»), инпуты и кнопки адаптированы под светлую и темную палитры.
- [x] **Сохранение выбранной темы** в `chrome.storage.local`.
- [x] **Анимированная спектральная призма**: индикатор прогресса сортировки с оптической анимацией преломления луча.

### 4. Качество кода и тестирование
- [x] Полная типизация TypeScript в строгом режиме (`strict: true`).
- [x] Очистка неиспользуемого кода и файлов.
- [x] Набор unit-тестов Vitest: **55/55 тестов** (`cleanup`, `chromeTabsService`, `themes`, `deterministic`, `semantic`).
- [x] Свежий скомпилированный бандл в директории `dist/`.

## 🔮 Что предстоит сделать (Roadmap / Backlog)

- [ ] **Drag-and-Drop в попапе**: перетаскивание вкладок между группами прямо внутри интерфейса расширения.

### Приоритет 3 (Дистрибуция и экосистема):
